## 🔧 原文件功能说明

### RealtimeSpeechSession 类

**主要功能**:
- 实时语音识别会话管理
- 音频块流式处理
- 文本确认与候选机制
- 智能标点预测
- 自动纠错

**核心方法**:
```python
class RealtimeSpeechSession:
    def __init__(self)                          # 初始化会话
    def process_realtime_audio(self)            # 处理实时音频
    def finalize_current_sentence(self)         # 完成当前句子
    def predict_punctuation(self, text, silence)# 预测标点
    def _auto_correct_text(self, text)          # 自动纠错
```

**状态字段**:
- `audio_chunks: List[bytes]` - 音频块列表
- `full_sentence: str` - 完整句子
- `confirmed_sentences: List[str]` - 已确认句子列表
- `_live_text: str` - 当前段落流式文本
- `_segment_revision: int` - 段落版本号

---

## ⚠️ 废弃原因

### 1. 架构问题

**状态管理复杂**:
- 存在多个冗余字段（`confirmed_text`、`candidate_text`、`full_sentence`）
- 状态转换逻辑不清晰
- 字段间关系混乱，难以维护

**代码示例**（问题代码）:
```python
# 🗑️ 废弃但仍保留的字段（未使用但占用空间）
self.confirmed_text = ""      # 废弃
self.candidate_text = ""      # 废弃
self.text_stability_tracker = {}  # 废弃
```

### 2. 缓冲区裁剪问题

**问题代码**:
```python
# ❌ 原问题代码（已注释但仍存在于文件中）
max_buffer_size = self.sample_rate * 10
if self.audio_buffer.size > max_buffer_size:
    # 裁剪导致上下文丢失，引起"吞字回删"
    self.audio_buffer = self.audio_buffer[-max_buffer_size:]
```

**影响**:
- 音频上下文丢失
- 识别结果不稳定
- 用户体验差（文本回删）

### 3. 双模型调用混乱

**问题**:
- 同时使用 ModelScope 离线识别 + FunASR 流式识别
- 代码逻辑分散在多个方法中
- 维护成本高，难以理解

## 🆕 新架构替代方案

### 新架构位置

```
e-voice/speech_recognition/streaming/
├── engine.py              # StreamingEngine - 流式推理引擎
├── state.py               # StreamingState - 状态管理
├── text_accumulator.py    # TextAccumulator - 文本累积器
├── loader.py              # ModelLoader - 模型加载器
└── bundle.py              # ModelBundle - 模型打包
```

### 核心改进对比

| 方面 | 旧架构 (session.py) | 新架构 (streaming/) | 改进 |
|-----|-------------------|-------------------|------|
| **状态管理** | 复杂，20+ 字段 | 清晰，单一 StreamingState | ⭐⭐⭐⭐⭐ |
| **缓冲区处理** | 裁剪导致丢失 | 保持完整缓冲区 | ⭐⭐⭐⭐⭐ |
| **模型调用** | 双模型混用 | 统一 FunASR 流式 | ⭐⭐⭐⭐ |
| **代码行数** | 2000+ 行单文件 | 模块化，5 个文件 | ⭐⭐⭐⭐ |
| **可维护性** | 低 | 高 | ⭐⭐⭐⭐⭐ |

### 迁移路径

**旧代码**:
```python
from server.session import RealtimeSpeechSession

session = RealtimeSpeechSession()
session.process_realtime_audio()
```

**新代码**:
```python
from speech_recognition.streaming.engine import StreamingEngine
from speech_recognition.streaming.state import StreamingState

state = StreamingState(...)
engine = StreamingEngine()
events = engine.push(audio_chunk, state)
```

**详细迁移指南**: `01-修复计划.md`
