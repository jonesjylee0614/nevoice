## 背景说明

### 现状
E-Voice 是基于 FunASR 开发的医院定制语音识别项目，目前实时语音识别存在以下问题：
- ❌ 展示错乱：文本频繁闪回、跳跃
- ❌ 纠正逻辑混乱：无法准确标识删除/新增位置
- ❌ 用户体验差：不如 FunASR 官方 demo 顺滑

### 架构现状
项目中存在**新旧双架构并存**的情况：

#### 旧架构（已标记废弃但仍在运行）
- **文件**: `nevoice/e-voice/server/session.py`
- **核心类**: `RealtimeSpeechSession`
- **状态**: 遗留代码，与新架构冲突

#### 新架构（重构版本，设计良好）
- **目录**: `nevoice/e-voice/speech_recognition/streaming/`
- **核心组件**:
  - `engine.py` - StreamingEngine（流式推理引擎）
  - `text_accumulator.py` - TextAccumulator（文本累积器）
  - `state.py` - StreamingState（状态管理）
  - `bundle.py` - ModelLoader（模型加载器）

### 核心判断
**新架构设计优秀，问题出在实现细节，无需完全重构！**

### 问题详解

#### P0-1: 事件顺序混乱
**症状**: 前端收到的 `partial` 和 `correction` 事件乱序，导致文本闪回

**当前代码** (`ws.py:78-105`):
```python
def _send_events(ws, events, state, request_id):
    for event in events:
        # ❌ 直接发送，未排序
        ws.send(json.dumps(event))
```

**修复方案**:
```python
def _send_events(ws, events, state, request_id):
    # ✅ 按 revision_id 严格排序
    events = sorted(events, key=lambda e: e.get('text_state', {}).get('revision_id', 0))
    for event in events:
        ws.send(json.dumps(event))
```

#### P1-1: 差异算法过于简单
**症状**: 纠正提示不准确，误判中间修改

**问题示例**:
```
原文: "今天天气真好"
纠正: "今天的天气真好"

当前算法误判为：
  删除: "天气真好"
  新增: "的天气真好"

应该判断为：
  在位置2插入: "的"
```

**当前代码** (`text_accumulator.py:18-26`):
```python
def diff(self, new_text: str) -> Tuple[str, str]:
    # ❌ 简单前缀匹配
    prefix_len = 0
    for old_ch, new_ch in zip(self.confirmed_text, new_text):
        if old_ch != new_ch:
            break
        prefix_len += 1

    removed = self.confirmed_text[prefix_len:]
    appended = new_text[prefix_len:]
    return removed, appended
```

**修复方案** (使用编辑距离算法):
```python
from difflib import SequenceMatcher

def diff(self, new_text: str) -> List[Dict]:
    """使用编辑距离算法精确计算差异"""
    matcher = SequenceMatcher(None, self.confirmed_text, new_text)
    changes = []

    for tag, i1, i2, j1, j2 in matcher.get_opcodes():
        if tag == 'delete':
            changes.append({
                'type': 'delete',
                'text': self.confirmed_text[i1:i2],
                'position': i1
            })
        elif tag == 'insert':
            changes.append({
                'type': 'insert',
                'text': new_text[j1:j2],
                'position': i1
            })
        elif tag == 'replace':
            changes.append({
                'type': 'replace',
                'old': self.confirmed_text[i1:i2],
                'new': new_text[j1:j2],
                'position': i1
            })

    return changes
```

### 阶段二：算法优化（P1）

#### 任务 2.1：升级差异算法
**文件**: `nevoice/e-voice/speech_recognition/streaming/text_accumulator.py`
**修改内容**:
```python
from difflib import SequenceMatcher
from typing import List, Dict

class TextAccumulator:
    def diff(self, new_text: str) -> List[Dict]:
        """
        使用编辑距离算法精确计算差异

        返回示例:
        [
            {'type': 'delete', 'text': '好', 'position': 5},
            {'type': 'insert', 'text': '不错', 'position': 5}
        ]
        """
        matcher = SequenceMatcher(None, self.confirmed_text, new_text)
        changes = []

        for tag, i1, i2, j1, j2 in matcher.get_opcodes():
            if tag == 'delete':
                changes.append({
                    'type': 'delete',
                    'text': self.confirmed_text[i1:i2],
                    'position': i1,
                    'length': i2 - i1
                })
            elif tag == 'insert':
                changes.append({
                    'type': 'insert',
                    'text': new_text[j1:j2],
                    'position': i1,
                    'length': j2 - j1
                })
            elif tag == 'replace':
                changes.append({
                    'type': 'replace',
                    'old_text': self.confirmed_text[i1:i2],
                    'new_text': new_text[j1:j2],
                    'position': i1,
                    'old_length': i2 - i1,
                    'new_length': j2 - j1
                })

        return changes

    def apply_correction(self, text: str) -> Dict[str, Any]:
        """应用纠错并返回详细差异"""
        changes = self.diff(text)

        # 记录到历史
        if changes:
            self.history.append({
                'timestamp': time.time(),
                'changes': changes
            })

        self.confirmed_text = text
        self.candidate_text = ""
        self.revision_id += 1

        return {
            "confirmed_text": self.confirmed_text,
            "candidate_text": "",
            "revision_id": self.revision_id,
            "changes": changes  # ✅ 返回详细差异
        }
```

**前端适配** (`realtime-correction-demo.html`):

```javascript
// 配置参数（参考 FunASR 官方）
const SAMPLE_RATE = 16000;
const CHUNK_SIZE = 9600;      // 600ms @ 16kHz
const CHUNK_STRIDE = 9600;    // 每次步进 600ms

let audioBuffer = [];

// 修改音频处理器
const scriptProcessor = audioContext.createScriptProcessor(4096, 1, 1);
scriptProcessor.onaudioprocess = function(audioProcessingEvent) {
    if (!isRecording) return;

    const inputBuffer = audioProcessingEvent.inputBuffer.getChannelData(0);

    // ✅ 累积音频到缓冲区
    audioBuffer.push(...inputBuffer);

    // ✅ 当累积到 CHUNK_STRIDE 时发送
    while (audioBuffer.length >= CHUNK_STRIDE) {
        const chunk = audioBuffer.slice(0, CHUNK_STRIDE);
        audioBuffer = audioBuffer.slice(CHUNK_STRIDE);

        // 转换为 Int16 PCM
        const int16Array = new Int16Array(chunk.length);
        for (let i = 0; i < chunk.length; i++) {
            const s = Math.max(-1, Math.min(1, chunk[i]));
            int16Array[i] = s < 0 ? s * 0x8000 : s * 0x7FFF;
        }

        // Base64 编码并发送
        const base64 = arrayBufferToBase64(int16Array.buffer);
        socket.emit('audio_chunk', {
            audio: base64,
            sample_rate: SAMPLE_RATE,
            format: 'pcm'
        });
    }
};
```
