# 实时识别 + 智能纠错实施计划

## 1. 项目目标

- 复刻 FunASR 2pass 实时识别架构，重写 WebSocket 链路，实现在 500ms 内的低延迟在线输出与高精度句尾纠错。
- 打通热词、声纹等增强字段，并统一输出协议，确保客户端可无缝对接。
- 构建端到端可观测能力，覆盖实时延迟、纠错耗时与会话状态监控。
- 平滑迁移并下线旧实时方案，保证灰度期间 v1/v2 双轨并存、最终彻底收敛到 v2。

## 2. 实施范围

- `nevoice/e-voice`：配置、流式识别引擎、WebSocket 路由、会话管理、监控指标。
- `nevoice/e-voice-admin`：开放接口配置、凭证管理、网关路由。
- `nevoice/e-voice-admin-front`：实时识别测试页面与 WebSocket 客户端封装。
- FunASR 子模块：模型加载、协议对齐（参考 `FunASR/runtime` 示例）。
- 自动化测试：单元测试、协议回归、端到端脚本。

## 4. 关键工作包与任务清单

### 4.1 协议层与会话管理

- ✅ `nevoice/e-voice/server/routes/ws.py` → 拆分并实现 `ws_v2.py`，遵循 FunASR WebSocket 协议。
- ✅ 新增 `register_ws_routes`，处理启动帧、音频帧、控制帧，统一响应结构。
- ✅ 引入 `server/services/streaming_session.py`，负责会话生命周期。
- 待开发 在 Gateway (`e-voice-admin`) 增加 `/ws/recognize?v=2` 路由与鉴权配置，灰度期间保持 v1/v2 共存。

### 4.2 Streaming 引擎与状态管理

- ✅ 新建目录 `speech_recognition/streaming/`，包含 `engine.py`, `state.py`, `text_accumulator.py`, `loader.py`。
- ✅ `loader.py` 统一加载 FunASR 模型（VAD、Online Paraformer、Offline Paraformer、Punc、ITN），支持 GPU/CPU 选择与半精度配置。
- ✅ `state.py` 定义 `StreamingState` 数据类：chunk 缓冲、VAD 状态、segment 序号、热词/声纹上下文、统计指标。
- ✅ `engine.py` 实现 `push()` 与 `flush()`，产出事件序列 `partial_result`、`correction`。
- ✅ `text_accumulator.py` 维护 `confirmed_text`、`candidate_text`、`revision_id`，支持增量渲染与二次纠错融合。

### 4.3 二次纠错（2pass）与文本处理

- ✅ 绑定 VAD 事件与 `chunk_interval`，识别 `speech_end` 时将缓存音频送入 Offline ASR。
- ✅ 整合离线 ASR、Punc、ITN，输出 `2pass-offline` 结果，确保与在线结果字段一致。
- ✅ 设计纠错触发策略：对比在线/离线文本差异，更新 `revision_id` 并推送 `correction` 消息。
- ✅ 配置热词、ITN 参数透传，确保 Offline 阶段也能识别增强词汇。

### 4.4 配置、监控与运维

## 6. 验收标准

- 功能：覆盖在线输出、离线纠错、热词声纹透传、协议一致性。
- 性能：单实例 ≥50 并发流、平均延迟 <400ms、纠错延迟 <2s。
- 稳定：会话超时回收、资源占用受控、错误码与异常处理完备。
- 质量：Black + Ruff、单测覆盖 ≥80%，端到端脚本可复现关键场景。
- 运维：监控告警就绪、日志字段齐全、回滚方案明确（P3）。
- 文档：`开放接口设计.md` 发布新版，附带 SDK 封装说明与更新日志（P3）。

## 7. 风险与缓解

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| 模型加载耗时与显存占用 | 启动慢、OOM | 预热 + 半精度、调研 CPU 备选、按需懒加载 |
| 协议升级导致客户端不兼容 | 客户端报错 | 网关版本切换、提供 SDK 示例、灰度回滚 |
| 离线纠错阻塞在线推理 | 延迟飙升 | 独立线程池、限流策略、异步回调 |
| 监控缺失导致问题难定位 | 运维风险 | 提前定义指标、接入日志平台、压测验证 |
| 资源争用影响 REST 服务 | 服务质量下降 | 进程内资源隔离、CPU 亲和、容量评估 |
