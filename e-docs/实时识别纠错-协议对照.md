# 实时识别协议对照（FunASR ↔ nevoice v2）

> 依据 FunASR 官方文档与 demo (`FunASR/runtime/python/websocket/funasr_wss_server.py`、`FunASR/runtime/docs/websocket_protocol_zh.md`) 整理，作为 `nevoice/e-voice` 新版 WebSocket 实现与对外接口文档更新的基线。

## 1. 握手与鉴权

| 项目 | FunASR Demo | nevoice v2 目标 | 说明 |
| --- | --- | --- | --- |
| URL | `ws://<host>:<port>/funasr/ws` | `wss://<domain>/ws/recognize?v=2` | 通过网关统一接入，强制 HTTPS/WSS |
| 查询参数 | `app_id`、`token`（可选） | `x-ak`、`x-t`、`x-sign` | 复用现有鉴权体系；`x-sign=MD5(app_key + app_secret + x-t)` |
| 子协议 | 默认无 | `binary`（可选） | 若需与浏览器端兼容，可不设子协议 |
| 超时策略 | 默认 5s 静默断开 | `idle_audio_timeout_ms=5000`、`max_session_ms=300000` | 参数放入配置文件，支持热更新 |

## 2. 客户端上行消息对照

### 2.1 配置消息（JSON）

| 字段 | FunASR | nevoice v2 | 备注 |
| --- | --- | --- | --- |
| `mode` | `"online"` / `"2pass"` | 同 FunASR | 目标保持一致，默认 `2pass` |
| `chunk_interval` | 毫秒，控制帧粒度 | 同 FunASR | 写入 `StreamingState`，影响推理节奏 |
| `sample_rate`/`audio_fs` | 音频采样率 | `audio_fs` | 默认 `16000`，需校验 |
| `hotwords` | JSON 字符串 | JSON 对象 | 服务端解析为 dict，提高易用性 |
| `speaker_id` | 可选 | 同 FunASR | 透传声纹增强字段 |
| `itn`/`enable_itn` | 布尔 | `itn` | 默认为 `true` |
| `streaming` | `true/false` | `mode` 区分 | 由 `mode` 决定，无需额外字段 |

### 2.2 音频帧

| 项目 | FunASR | nevoice v2 | 说明 |
| --- | --- | --- | --- |
| 形式 | Binary，PCM16 | 保持一致 | 最低 20ms/帧，最高 16KB |
| JSON 包裹 | 支持 `{"chunks": ...}` | 不再支持 | 彻底改为二进制帧 |
| 控制帧 | `{"command":"stop"}` 等 | `{"is_speaking": false}` | 统一控制字段名称 |

### 2.3 控制消息

| 场景 | FunASR | nevoice v2 | 说明 |
| --- | --- | --- | --- |
| 停止讲话 | `{"mode":"offline"}` / `stop` | `{"is_speaking": false}` | 保留单一语义字段 |
| 热词更新 | `{"hotwords": "..."}` | `{"hotwords": {...}}` | v2 支持多次热更新 |
| 心跳 | `{"command":"heartbeat"}` | `{"ping": 1}` | 响应 `{"pong":1}` |

## 3. 服务端下行消息对照

| 字段 | FunASR 字段含义 | nevoice v2 字段 | 兼容策略 |
| --- | --- | --- | --- |
| `type` | `"start"/"result"/"end"` | `type` (`started`/`partial`/`final`/`correction`) | 统一消息类型枚举 |
| `mode` | `"2pass-online"`、`"2pass-offline"` | `mode` (`realtime`/`offline`) | 精简取值，外部文档沿用 |
| `sequence` | 自增序号 | `revision` | 双方都用 int64，自增 |
| `text` | 当前文本 | `text` | 直接沿用 |
| `timestamp` | ms | `timestamps.event_ms` | v2 将时间字段收拢在 `timestamps` |
| `is_final` | bool | `is_final` | 含义一致 |
| `lan` | 语言 | `language` | 改为全名 `zh-CN` |
| `message_id` | 唯一 ID | `segment_id` | 用于客户端去重 |
| `trace_id` | 追踪 | `request_id` | 与网关一致 |
| `time_cost` | 延迟 | `latency_ms.total` | 按阶段拆分 `realtime`/`offline` |
| `hotword_list` | 应用热词 | `meta.hotwords` | 以数组返回 |

## 4. 错误码映射

| FunASR 错误 | 描述 | nevoice v2 对应 | 备注 |
| --- | --- | --- | --- |
| `4001` | 参数缺失 | HTTP 400 + `{"code":440001}` | 保持 JSON 错误体 |
| `4002` | 采样率不支持 | `440002` | 附带 `supported=[8000,16000]` |
| `4004` | 会话未初始化 | `440004` | 提醒先发送配置 |
| `4099` | 会话冲突 | `440003` | 正在补偿阶段，拒绝新音频 |
| `4101` | 鉴权失败 | HTTP 401 + `40101` | 复用现有签名体系 |
| `4299` | 限流 | HTTP 429 + `42901` | 附带 `suggest_fps` |
| `5001` | 内部错误 | HTTP 500 + `50001` | 提供 `trace_id` |
