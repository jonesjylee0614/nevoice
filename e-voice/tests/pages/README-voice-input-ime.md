# E-Voice 语音输入法 - 使用指南

> 🎤 **专业的语音输入界面，类似Windows语音输入法的体验**

## 📋 概览

`voice-input-ime.html` 是一个全新设计的语音输入法界面，提供简洁、流畅、专业的语音转文字体验。

### 访问地址

```
http://localhost:8210/tests/pages/voice-input-ime.html
```

或直接在浏览器中打开HTML文件。

---

## ✨ 核心特性

### 1. 输入法风格界面

- **双区域显示**:
  - ✅ **确认文本区**: 显示已确认的文本（黑色正体）
  - ⚡ **实时识别区**: 显示正在识别的文本（蓝色斜体）

- **类Windows体验**:
  - 说话时实时显示在识别区
  - 停顿1.5秒自动确认到文本区
  - 可以连续说多句话，自动分段

### 2. 智能纠错可视化

- **纠错高亮**: 纠错后的文字会有黄色高亮动画
- **纠错记录**: 自动记录所有纠错历史
  - 显示原始文本 → 纠正后文本
  - 包含时间戳
  - 最多保存20条记录

- **纠错统计**: 实时显示纠错次数

### 3. 便捷操作

#### 一键录音
- 点击中央大按钮开始/停止录音
- 录音时按钮变红色并有脉冲动画
- 声波动画提供视觉反馈

#### 快捷键支持
- **空格键**: 按住开始录音，松开停止（可在设置中关闭）
- **Ctrl+C**: 快速复制全部文本

#### 功能按钮
- 📋 **复制**: 一键复制所有已确认文本到剪贴板
- 🗑️ **清除**: 清空所有内容（需先停止录音）
- ⚙️ **设置**: 打开设置面板

### 4. 实时统计

- ⏱️ **录音时长**: 显示当前录音时间
- 📝 **句子数量**: 统计已确认的句子数
- ✨ **纠错次数**: 显示智能纠错的总次数

### 5. 自动连接

- 页面加载后自动连接到WebSocket服务器
- 断线后自动重连（5秒间隔）
- 实时显示连接状态

## 📖 使用步骤

### 1. 启动服务

确保E-Voice后端服务已启动：

```bash
cd e-voice
export EVOICE_ENV=dev
python rest.py
```

服务运行在 `http://0.0.0.0:8210`

### 2. 打开页面

在浏览器中访问：
```
http://localhost:8210/tests/pages/voice-input-ime.html
```

或直接打开HTML文件。

### 3. 检查连接

- 查看右上角状态指示器
- **绿点 + "已连接"**: 表示已成功连接
- **红点 + "未连接"**: 表示连接失败，会自动重连

### 4. 开始使用

**方式一：点击按钮**
1. 点击中央的麦克风按钮🎤
2. 允许浏览器访问麦克风
3. 开始说话
4. 点击红色按钮⏹️停止录音

**方式二：空格键快捷操作**（推荐）
1. 按住空格键
2. 开始说话
3. 松开空格键
4. 系统自动处理识别结果

### 5. 查看结果

- **实时识别**: 说话时在"实时识别"区看到蓝色文字
- **自动确认**: 停顿1.5秒后自动移到"确认文本"区
- **智能纠错**: 纠错后会有黄色高亮动画
- **纠错记录**: 在底部纠错面板查看所有修正

### 6. 复制文本

- 点击"📋 复制"按钮
- 或按 `Ctrl+C`
- 所有已确认文本已复制到剪贴板

## ⚙️ 设置选项

点击"⚙️ 设置"按钮打开设置面板：

### 服务器地址
- 默认: `ws://localhost:8210/ws/recognize`
- 支持自定义WebSocket地址

### 识别选项

| 选项 | 说明 | 默认 |
|------|------|------|
| **启用智能纠错** | 使用离线ASR纠正识别错误 | ✅ 开启 |
| **显示实时识别** | 显示在线ASR的实时结果 | ✅ 开启 |
| **自动标点符号** | 自动添加标点和格式化 | ✅ 开启 |
| **显示纠错记录** | 在底部显示纠错历史 | ✅ 开启 |
| **启用空格键快捷操作** | 按住空格键录音 | ✅ 开启 |

### 保存设置

- 点击"💾 保存设置"保存到本地存储
- 下次打开自动加载上次设置
- 点击"🔄 恢复默认"重置所有设置

## 💡 使用技巧

### 1. 获得最佳识别效果

**环境要求**:
- 安静的环境（减少背景噪音）
- 距离麦克风15-30厘米
- 正常音量说话（不要太小声或太大声）

**说话技巧**:
- 清晰发音，不要含糊
- 正常语速（不要太快或太慢）
- 停顿1.5秒等待自动确认
- 可以连续说多句话

### 2. 智能纠错的使用

**自动纠错场景**:
```
说话: "今天天气争好"
在线识别: 今天天气争好 (蓝色)
智能纠错: 今天天气真好。(黄色高亮 + 黑色)
```

**查看纠错记录**:
- 底部自动展开纠错面板
- 显示: 争好 → 真好
- 包含纠错时间戳

### 3. 空格键快捷操作

**推荐使用场景**:
- 需要频繁录音
- 打字时临时切换语音输入
- 快速记录想法

**注意事项**:
- 不要在输入框中按空格键（会正常输入空格）
- 确保不在其他输入框中
- 可在设置中关闭此功能

### 4. 连续输入多段文字

```
说话1: "今天天气真好" → 停顿1.5秒 → 自动确认
说话2: "我们去公园吧" → 停顿1.5秒 → 自动确认
说话3: "下午三点见" → 停顿1.5秒 → 自动确认

最终结果:
今天天气真好。
我们去公园吧。
下午三点见。
```

### 5. 复制到其他应用

1. 在E-Voice中完成语音输入
2. 点击"📋 复制"或按`Ctrl+C`
3. 切换到目标应用（如Word、微信等）
4. 粘贴 `Ctrl+V`

## 🔧 常见问题

### Q1: 无法连接到服务器

**症状**: 右上角显示"未连接"，红点闪烁

**解决方案**:
1. 检查后端服务是否启动
   ```bash
   curl http://localhost:8210/health
   ```
2. 检查服务器地址配置是否正确
3. 查看浏览器控制台错误信息
4. 确认防火墙/代理设置

### Q2: 麦克风权限被拒绝

**症状**: 点击录音按钮提示"无法访问麦克风"

**解决方案**:
1. 点击浏览器地址栏左侧的🔒图标
2. 找到"麦克风"权限设置
3. 选择"允许"
4. 刷新页面重试

**Chrome设置**:
```
设置 → 隐私和安全 → 网站设置 → 麦克风 → 允许访问
```

### Q3: 没有识别结果

**症状**: 录音正常但没有文字显示

**可能原因**:
1. 模型未加载成功 → 查看后端日志
2. 音频格式不匹配 → 确认采样率16kHz
3. 麦克风静音 → 检查系统音量设置
4. 网络问题 → 检查WebSocket连接

**排查步骤**:
```bash
# 1. 查看后端日志
tail -f logs/ws.log

# 2. 检查模型状态
curl http://localhost:8210/status/model

# 3. 测试音频
# 在页面中查看声波动画是否活跃
```

### Q4: 识别延迟很高

**症状**: 说话后3-5秒才显示文字

**优化方案**:
1. **关闭实时识别**（只使用最终结果）
   - 设置 → 取消勾选"显示实时识别"

2. **使用GPU加速**
   ```yaml
   # config/realtime.yml
   resources:
     device: "cuda"
   ```

3. **减少并发会话**
   - 确保只有一个录音窗口

4. **调整音频块大小**
   - 减少CHUNK_SIZE可降低延迟

### Q5: 文本出现乱序

**症状**: 已确认的文本突然被修改

**解决方案**:
- 此页面已实现revision_id时序校验
- 过期事件会被自动丢弃
- 如仍出现问题，清除页面后重试

### Q6: 空格键不起作用

**检查项**:
1. 是否在设置中启用了"启用空格键快捷操作"
2. 当前焦点是否在输入框中（如果在，空格键会正常输入空格）
3. 尝试点击页面空白处，再按空格键

## 🎯 使用场景

### 1. 会议记录

**场景**: 实时记录会议讨论内容

**使用方法**:
1. 打开页面，点击录音按钮
2. 会议进行时持续录音
3. 系统自动分段识别发言
4. 会议结束后复制全文

**优势**:
- 自动分句，结构清晰
- 智能纠错，准确率高
- 一键复制，方便整理

### 2. 文章撰写

**场景**: 口述文章内容，快速生成文字稿

**使用方法**:
1. 构思好内容框架
2. 按段落口述
3. 每段停顿1.5秒自动确认
4. 完成后复制到Word编辑

**技巧**:
- 每段内容控制在1-2分钟
- 重要数字和专有名词清晰发音
- 利用纠错记录检查错误

### 3. 即时笔记

**场景**: 快速记录临时想法和灵感

**使用方法**:
1. 按住空格键
2. 快速说出想法
3. 松开空格键
4. 继续工作，稍后查看

**优势**:
- 空格键快捷操作，无需切换窗口
- 不打断工作流程
- 自动保存识别结果

### 4. 语音邮件/消息

**场景**: 口述邮件或即时消息内容

**使用方法**:
1. 在E-Voice中口述内容
2. 复制识别结果
3. 粘贴到邮件客户端或聊天工具
4. 简单修改后发送

**适用于**:
- 微信/QQ消息
- 邮件正文
- 工作日报
- 客户回复

### 5. 编程注释

**场景**: 为代码添加中文注释

**使用方法**:
1. 在E-Voice中说出注释内容
2. 复制文本
3. 在IDE中格式化为注释
4. 添加到代码中

**示例**:
```python
# 说话: "这个函数用于计算两个数字的最大公约数"
# 识别: 这个函数用于计算两个数字的最大公约数。
# 粘贴:
def gcd(a, b):
    """这个函数用于计算两个数字的最大公约数。"""
    ...
```

## 🔬 技术细节

### 架构设计

```
┌─────────────┐
│  浏览器界面  │
│ (voice-input│
│  -ime.html) │
└──────┬──────┘
       │ WebSocket
       ↓
┌─────────────────┐
│  E-Voice后端    │
│  /ws/recognize  │
└────────┬────────┘
         │
    ┌────┴────┐
    │ 在线ASR │ (实时识别)
    │ 离线ASR │ (精准纠错)
    │   VAD   │ (语音检测)
    │  PUNC   │ (标点恢复)
    │   ITN   │ (文本规范)
    └─────────┘
```

### 消息协议

**客户端 → 服务器**:

```javascript
// 开始录音
{
  "type": "start",
  "enable_correction": true,
  "enable_itn": true,
  "enable_partial": true
}

// 音频数据
{
  "type": "chunk",
  "format": "pcm",
  "sample_rate": 16000,
  "audio": "base64_encoded_pcm_data"
}

// 结束录音
{
  "type": "end"
}
```

**服务器 → 客户端**:

```javascript
// 实时识别结果
{
  "type": "partial",
  "text": "今天天气",
  "text_state": {
    "confirmed_text": "",
    "candidate_text": "今天天气",
    "revision_id": 1
  }
}

// 最终确认结果
{
  "type": "final",
  "text": "今天天气真好。",
  "text_state": {
    "confirmed_text": "今天天气真好。",
    "candidate_text": "",
    "revision_id": 5
  }
}

// 智能纠错结果
{
  "type": "correction",
  "text": "今天天气真好。",
  "raw_text": "今天天气争好",
  "text_state": {
    "confirmed_text": "今天天气真好。",
    "candidate_text": "",
    "revision_id": 6,
    "changes": [...]
  }
}
```

### 性能指标

| 指标 | 数值 | 说明 |
|------|------|------|
| 端到端延迟 | 200-400ms | 说话到显示时间 |
| 在线识别延迟 | <200ms | 实时识别响应时间 |
| 离线纠错延迟 | 1-2s | 停顿后的纠错时间 |
| 音频块大小 | 9600 samples | 600ms @ 16kHz |
| 识别准确率 | 95-98% | 2-Pass模式 |

```javascript
  "showPartial": true,
  "autoPunctuation": true,
  "showCorrections": true,
  "spaceKeyShortcut": true
}
```
