# HTML测试页面使用说明

## 文件说明
- `test_page.html` - 主测试页面
- `test_api.sh` - Linux命令行测试脚本
- `README.md` - 完整文档说明

## 如何使用HTML测试页面

### 1. 启动服务器
```bash
python rest.py
```

### 2. 打开测试页面
用浏览器打开 `tests/test_page.html` 文件

### 3. 配置服务器地址
- 页面顶部可以修改服务器地址（默认：http://localhost:5000）
- 点击"检查连接"按钮验证服务器状态

## 功能介绍

### 🔧 服务器配置
- **服务器地址设置**: 可以修改目标服务器URL
- **连接状态检查**: 实时检查服务器是否在线
- **状态指示器**: 绿色=在线，红色=离线，黄色=检查中

### 🏥 健康检查接口
- **功能**: 测试 `GET /` 接口
- **用途**: 验证服务器基本功能
- **预期响应**: "success"

### 🧠 Embedding接口
- **功能**: 测试 `POST /embedding` 接口
- **输入**: JSON格式数据
- **示例**: `{"test": "data", "message": "hello"}`
- **用途**: 测试JSON数据处理

### 🎤 语音注册接口
- **功能**: 测试 `POST /voice-register` 接口
- **输入参数**:
  - 用户名 (username)
  - 用户ID (userid)
  - 音频文件 (支持拖拽上传)
- **支持格式**: WAV, MP3, M4A等
- **特性**: 文件大小显示，拖拽上传

### 🛠️ 自定义接口测试
- **功能**: 测试任意HTTP接口
- **支持方法**: GET, POST, PUT, DELETE, OPTIONS
- **自定义内容**:
  - 接口路径
  - 请求头 (JSON格式)
  - 请求体
- **用途**: 测试新增接口

### 📊 批量测试
- **功能**: 一键测试所有可用接口
- **测试项目**:
  - 健康检查
  - Embedding接口
  - CORS支持检查
- **结果**: 显示每个接口的通过/失败状态

## 界面特性

### 🎨 视觉设计
- **现代化UI**: 渐变背景，卡片式布局
- **响应式设计**: 自适应手机、平板、桌面
- **状态指示**: 不同颜色表示不同状态
- **加载动画**: 请求过程中显示加载效果

### 📱 交互体验
- **拖拽上传**: 支持文件拖拽到上传区域
- **实时反馈**: 立即显示响应结果
- **JSON格式化**: 自动美化JSON响应
- **错误处理**: 友好的错误信息显示

### ⚡ 性能功能
- **响应时间**: 显示每个请求的耗时
- **状态码**: 清晰显示HTTP状态码
- **内容格式化**: 自动检测和格式化响应内容

## 使用技巧

### 1. 测试新接口
当rest.py添加新接口时：
1. 使用"自定义接口测试"功能
2. 设置正确的HTTP方法和路径
3. 配置必要的请求头和请求体
4. 测试成功后可以考虑添加到批量测试中

### 2. 调试接口问题
1. 查看响应状态码判断问题类型
2. 检查响应时间判断性能问题
3. 查看详细响应内容了解错误信息
4. 使用批量测试对比不同接口状态

### 3. 文件上传测试
1. 准备测试音频文件（建议小文件优先）
2. 可以直接拖拽文件到上传区域
3. 注意观察文件大小信息
4. 上传较大文件时注意响应时间

### 4. 扩展页面功能
如需添加新的接口测试：
1. 复制现有接口的HTML结构
2. 修改接口标题、方法、描述
3. 添加对应的JavaScript测试函数
4. 更新批量测试功能包含新接口

## 常见问题

### Q: 页面显示"服务器离线"
A: 确保rest.py正在运行，检查端口5000是否被占用

### Q: 文件上传失败
A: 检查文件格式是否支持，文件大小是否过大

### Q: 自定义接口测试报错
A: 检查请求头JSON格式是否正确，路径是否以/开头

### Q: 批量测试部分失败
A: 正常现象，某些接口可能需要特定条件才能成功
